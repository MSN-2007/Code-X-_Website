## Overview

This is the official website for **Code{X}**, a student-led programming club that runs workshops, organizes hackathons, and participates in CTF competitions. The site serves as the club's digital hub — showcasing events, team members, and resources for students interested in tech and cybersecurity.

## Features

- 📅 **Events & Announcements** — Stay updated on upcoming workshops and competitions
- 👥 **Team Showcase** — Meet the club leadership and core members
- 🏆 **Achievements** — Highlights from hackathons, CTFs, and competitions
- 📚 **Resources** — Learning materials and workshop content for members
- 🎨 **Modern UI** — Clean, responsive design built with vanilla JS
